# File Master

**让 Obsidian 附件真正可控**：集**本地仓库整理**与**自建文件服务器**于一体的附件管理工作台。

**简体中文** · [English](README.md) · [服务端（file-master-server）](https://github.com/weichen-ink/file-master-server) · [更新记录](CHANGELOG.md)

---

## 为什么做 File Master？

用久了 Obsidian，附件管理通常会遇到这些头疼问题：
- **仓库越来越臃肿**：截图、图片、视频越存越多，拖慢跨端同步，却不敢随便删——生怕删掉哪张图导致旧笔记断链；
- **重复与“孤儿”文件泛滥**：同一张图反复粘贴产生多份副本，删掉笔记后附件还留在磁盘里占空间；
- **发博客 / 公众号很折腾**：本地图片带不走，手动传图床又得一篇篇改链接；
- **改个文件名牵一发而动全身**：远程文件改名后，散落在各篇笔记里的链接全部失效。

**File Master** 把这些问题收进同一套安全工作流：**不搭服务器也能做全库去重、孤儿清理与断链体检；接上自己的服务端，则解锁 WebP 自动优化、动态水印、跨笔记自动改名和云端回收站。**

## 核心工作流

### 1. 粘贴即整理，本地与云端双向自由迁移
- **粘贴 / 拖拽自动接管**：贴入图片、视频或任意文件时，按你的习惯自动保存到本地或上传至服务端，并插入对应链接。
- **单篇笔记一键迁移**：打开任意笔记，可将文内所有本地附件**一键上传到服务器**，或把远程链接**批量下载回本地**离线存档，文内链接自动重写。
- **支持多种文档格式**：全面兼容 **Markdown**、**Canvas** 和 **Excalidraw**。

### 2. 发文章神器：WebP 优化与一键带走
- **复制含 WebP 链接的笔记全文**：不改动原笔记，一键复制替换为 WebP 外链的 Markdown 全文，直接粘贴到博客、公众号或其它编辑器。
- **原文件 / WebP / Markdown 灵活复制**：画廊与预览弹窗中可随时切换原文件与 WebP 链接格式，并查看文件被哪些笔记引用。

### 3. 全库“大扫除”，而且绝不误删
- **SHA-256 精确去重**：按文件内容哈希找出完全相同的重复附件，保留一份并自动把所有笔记中的引用合并到保留文件上。
- **孤儿附件清理**：全库扫描未被任何笔记引用的闲置文件（支持一键批量清理，也可将重要文件设为**锁定保护**，使其不参与去重与清理）。
- **失效链接体检**：全库查出断链的 `[[wikilink]]`、缺失的本地图片以及返回 404 的远程链接；按笔记聚合展示，**悬停即可预览并定位到具体行号**，不用跳出当前窗口。
- **仓库分析仪表盘**：直观查看本地与远程附件数量、空间占用以及大文件排行。

### 4. 服务端文件改名，全库笔记自动跟随
- 重命名服务端文件前，自动扫描受影响的 Markdown / Canvas / Excalidraw 笔记并展示每条待更新链接（支持**悬停预览核对上下文**）。
- 提交后自动更新全库笔记引用，同时服务端为旧链接保留宽限期别名，外部博客文章不会立刻 404。

### 5. 随时预览、插入与反悔
- **画廊 & 桌面端侧边栏**：按目录、类型、排序与关键词快速检索服务端文件，支持大图缩放预览、原图/WebP 对比和直接插入当前笔记。
- **回收站兜底**：误删的服务端文件会先进入回收站，随时可一键还原或彻底清理。

## 纯本地 vs 搭配服务端

| 能力 | 纯本地模式（无需服务器） | 搭配 `file-master-server` |
| --- | :---: | :---: |
| 粘贴 / 拖拽附件整理 | ✅ | ✅ |
| 全库重复文件合并（SHA-256） | ✅ | ✅ |
| 孤儿附件扫描与安全清理 | ✅ | ✅ |
| 失效链接 / 断链体检 | ✅ | ✅ |
| 仓库附件空间分析 | ✅ | ✅ |
| 自动上传、WebP 压缩与动态水印 | — | ✅ |
| 跨笔记远程文件改名（含旧链接宽限期） | — | ✅ |
| 云端画廊、侧边栏浏览与回收站 | — | ✅ |

## 安全与多端设计

- **删除前二次引用校验**：执行删除或合并前再次校验最新笔记内容，若文件仍在被引用或刚刚被编辑，立即拦截保护。
- **断点恢复与操作日志**：批量上传、下载和跨笔记改名均支持异常中断后的状态恢复与日志追踪。
- **桌面端 & 移动端通用**：界面支持简体中文与 English，自动跟随 Obsidian 浅色/深色主题。

## 安装

### 方式一：使用 BRAT（推荐）

1. 在 Obsidian 社区插件中安装并启用 **BRAT**。
2. 在 BRAT 中添加仓库：`https://github.com/weichen-ink/file-master`。
3. 前往 **设置 → 第三方插件**，启用 **File Master**。

### 方式二：手动安装

1. 从 [Releases](https://github.com/weichen-ink/file-master/releases) 下载最新版本的 `main.js`、`manifest.json` 和 `styles.css`。
2. 将这 3 个文件放入知识库的 `.obsidian/plugins/file-master/` 目录。
3. 重载 Obsidian，在第三方插件中启用 **File Master**。

---

## 30 秒开始使用

1. 点击 Obsidian 左侧工具栏的 **File Master** 图标打开 Hub 面板（也可通过命令面板调用各项功能）。
2. **只用本地整理**：直接点击「重复文件合并」「孤儿附件清理」「失效链接检查」或「仓库分析」即可开始。
3. **连接自己的服务器（可选）**：
   - 按 [file-master-server 文档](https://github.com/weichen-ink/file-master-server) 部署服务端；
   - 在插件设置中开启服务器连接，填入站点地址与服务端「系统设置 → 站点设置」中的上传 API 令牌；
   - 点击 **测试连接**，通过后即可使用云端上传、画廊、改名与 WebP 复制。

> **提示**：插件与服务端均需 **1.1 及以上版本**（推荐同步升级到 **1.2.0+**）。在手机端使用时，服务器地址请填写手机可访问的局域网或公网域名，不要填写 `localhost`。
